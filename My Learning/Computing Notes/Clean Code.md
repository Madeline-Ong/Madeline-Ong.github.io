# Things to keep in mind when coding:

## Thought process

### KISS (Keep It Simple Stupid)
- can this be simplified / easier way?
every bit of code added means more to debug


## Understandability

### use one naming convention throughout
examples include: camelCase, snake_case, kebab-case

### don't use too simple of a name that you cannot identify
*might help to write down all used variable names somewhere
what is _total_? is it the total of everyone's spending? the total of IT department's income?
