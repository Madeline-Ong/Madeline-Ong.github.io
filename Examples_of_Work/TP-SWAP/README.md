Description of website: <br>
Our website is a HR website that helps in leave, MC and employee management.

Problem Statement: <br>
TP AMC currently uses books to keep track of their employees’ information, as they lack a way to have all their employee’s information to be centralized. This process of keeping and tracking information comes with many disadvantages that include efficiency, security, and monetary issues.

Steps to set up website:
1. In the website folder, copy and paste folder of "swap updated website" into C:\xampp\htdocs.
2. Import Database into phpMyAdmin (Note: There is currently no MC applications as when importing will have a prompt saying file too big).
3. Extract and copy PHPMailer folder into C:\xampp\php\pear.
